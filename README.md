# Curso de React

Repositorio utilizado para almacenar los proyectos, ejercicios y prácticas desarrollados durante el curso de **React**.

## Objetivo

Aprender y practicar los conceptos fundamentales de React mediante diferentes ejercicios y proyectos prácticos.

## Contenido

Durante el curso se trabajarán temas como:

- Componentes y JSX
- Props y estado
- Hooks
- Eventos y formularios
- Renderizado condicional
- Listas y componentes reutilizables
- Manejo de datos
- Consumo de APIs
- React Router
- Buenas prácticas
- Estructura y organización de proyectos
